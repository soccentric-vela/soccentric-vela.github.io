Repositories

Public repositories of this platform, in two categories.

Production

The software that ships on the device and runs the fleet: the OS image, configuration, on-device instrumentation and cloud management.

RepositoryRoleWhat it is
Vela-OSImage buildYocto and kas image build for the board
meta-velaYocto layerBSP and board layer used by the image build
Vela-ConfigurationWebConfigOn-device web configuration: Rust daemon and browser UI
Vela-InstrumentationInstrumentationOn-device management and observability
Vela-HQFleet managementFleet management service
Vela-HardwareHardware docsHardware documentation for the board

Validation & Verification

Independent validation and verification components. They run on top of the Production OS and its services to exercise and check them.

Get started

The image build is the best place to begin.

git clone https://github.com/soccentric-vela/Vela-OS.git

Then follow the README in that repository for build prerequisites and steps.

Contribute

Pull requests go to the develop branch and commits are signed off (git commit -s). See the contributing guide and the security policy.
